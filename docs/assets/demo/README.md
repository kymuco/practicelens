# PracticeLens Demo Assets

This directory contains a small curated demo bundle for the root README.

All files are synthetic/generated demo assets created from PracticeLens evaluation showcase data. They are not real musician recordings, not private user audio, and not a scientific benchmark.

Start with `report.svg` for the quickest visual preview, then open `practice_plan.md` for the recommended next-practice guidance and `batch_report.md` for the ranking details.

Audio examples:

- `audio/reference_phrase.ogg` - clean synthetic reference phrase.
- `audio/exact_take.ogg` - near-exact generated take.
- `audio/pitch_drift_take.ogg` - generated take that drifts upward in pitch.
- `audio/timing_drift_take.ogg` - generated take that gradually stretches timing against the reference.

The broader reproducible workflow is documented in the [Evaluation showcase](../../../examples/evaluation_showcase/README.md).

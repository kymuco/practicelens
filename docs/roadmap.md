# Roadmap Snapshot

This file is a practical snapshot of where PracticeLens appears to be going next.

It is intentionally lightweight and should stay more honest than ambitious.

## Current baseline

Already in place:

- offline single-take analysis;
- multi-take batch comparison;
- JSON / Markdown / CSV / SVG outputs;
- CLI workflows;
- optional API workflows;
- typed API payload contracts;
- CI and contributor-facing repo hygiene.

## Near-term priorities

### 1. Better evaluation and demo surface

The repo should become easier to judge quickly.

Examples:

- clearer demo assets;
- more realistic synthetic evaluation assets;
- more polished README presentation;
- stronger example outputs;
- easier first-run walkthroughs.

### 2. Reporting UX improvements

The project already produces useful artifacts, but there is room to make them more convincing.

Examples:

- tighter summaries;
- better SVG readability;
- stronger batch comparison presentation;
- more useful per-section artifact views.

### 3. API ergonomics

The API already exists and is typed more clearly now.

Logical next improvements include:

- stronger request/response examples;
- explicit schema documentation;
- clearer payload validation stories;
- lightweight integration examples.

### 4. Future scoring evolution

The deterministic baseline should stay strong.

Possible later work:

- stronger scoring calibration;
- better section-level heuristics;
- broader evaluation cases before heavier scoring changes;
- optional model-assisted scoring layered on top of deterministic features.

## Explicitly not the immediate goal

The roadmap does **not** currently prioritize:

- cloud-first infrastructure;
- complex orchestration layers;
- polyphonic-first redesign;
- pretending the project is already production-complete.

## Practical north star

PracticeLens should keep becoming:

- easier to evaluate;
- easier to trust;
- easier to run locally;
- more useful for single and batch practice review;
- more convincing as a disciplined developer-facing project.

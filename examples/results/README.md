# Sample Result Snapshots

This directory contains **illustrative output snapshots** that show how PracticeLens artifacts currently look.

These files are meant for:

- quick GitHub-side evaluation;
- demo browsing without running the project first;
- understanding artifact shape before using local WAV inputs.

## Important note

These are **demo snapshots**, not strict golden fixtures.

That means:

- they are representative;
- they follow the current report shape and style;
- they are useful for presentation and orientation;
- they should not be treated as permanent proof that exact future scores or wording will remain identical.

## Included examples

### `single/`

Illustrative single-take outputs:

- `report.json`
- `report.md`
- `report.csv`
- `report.svg`

### `batch/`

Illustrative multi-take comparison outputs:

- `batch_report.json`
- `batch_report.md`
- `batch_report.csv`
- `batch_report.svg`

## How to use these

- Open Markdown first for human-readable review.
- Open JSON if you want to inspect structure.
- Open CSV if you want spreadsheet-like comparison.
- Open SVG if you want the fastest visual impression.
